# ONA — bienestar para toda la familia

Sitio estático responsive inspirado en el diseño de referencia. Incluye encabezado minimalista, portada, beneficios, presentación de marca y contacto.

Abre `index.html` para ver la página. El botón principal, el botón de contacto y el botón flotante de WhatsApp eligen al azar entre 3507748968 y 3008806606, usando el prefijo internacional colombiano +57 y un mensaje listo para enviar.

La imagen de portada está incluida como `ona-hero.jpg`. Para publicar una nueva versión en GitHub Pages, sube y confirma todos los archivos del ZIP en la raíz del repositorio.
