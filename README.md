# ONA — sitio de muestra

Sitio estático responsive para ONA, con identidad en marfil, beige, café y verde oliva.

## Abrir el sitio

Abre `index.html` en un navegador. No requiere instalación ni servidor.

## WhatsApp

El botón verde flotante de la esquina inferior derecha y los botones de los productos eligen aleatoriamente uno de estos números y abren el chat con prefijo internacional colombiano `57`:

- 3507748968
- 3008806606

Los mensajes se pueden editar en `script.js`. Los productos y sus fotos son de muestra; reemplaza los datos y diseños cuando tengas las imágenes reales.
